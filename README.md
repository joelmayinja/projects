# Maximum Element in an Array (C++)

## Algorithm
1. Assume the first element is the maximum.
2. Loop through the array from index 1 to n-1.
3. If the current element is greater than the current maximum, update it.
4. Return the maximum value.

## How to Run
1. Compile:
   g++ max_element.cpp -o max

2. Run:
   ./max
